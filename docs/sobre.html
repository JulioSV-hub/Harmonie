Privacidade

Este site não tem cadastro para visitantes. As entradas do Diário de Gratidão ficam salvas somente no seu navegador e nunca são enviadas.

Os dados informados no pedido de agendamento (nome, data, horário e, se você preencher, e-mail e motivo) são enviados ao profissional pelo WhatsApp e registrados em sistema de acesso restrito a ele, apenas para organizar os atendimentos. Para pedir a exclusão desses dados, fale com o profissional.
